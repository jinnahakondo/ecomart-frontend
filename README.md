## 📌 Overview

**Ecomart** is a modern, scalable **full-stack e-commerce system** designed with real-world production patterns. It integrates:

- Secure authentication system (JWT + cookies)
- Role-based access control (User / Admin)
- Advanced product & order management system
- AI-powered features (Google Gemini API)
- Fully responsive UI with modern UX patterns
- Analytics dashboard with real-time insights

This project simulates enterprise-level e-commerce architecture.
